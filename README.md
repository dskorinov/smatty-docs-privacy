# Smatty privacy policies

Despite the repository name, this is the privacy policy page for all Smatty
apps, not only Smatty Docs. `index.html` has one section per app, served from
GitHub Pages at <https://dskorinov.github.io/smatty-docs-privacy/>:

| App | Section |
|-----|---------|
| Smatty Patty | `#smatty-patty` |
| Smatty Musician | `#smatty-musician` |
| Smatty Docs | `#smatty-docs` |

Each app's Play listing points here. When an app's policy changes, edit only
its section and its "Last updated" date. A new app gets a new section and a
line in the list at the top of the page.

The old `smatty-patty-privacy` and `smatty-musician-privacy` repositories are
no longer used.
